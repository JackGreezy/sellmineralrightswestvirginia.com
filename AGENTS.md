# Sell Mineral Rights West Virginia — Site-Specific Rules

This project has its own Appalachian abstract-desk voice and its own ICEYE-derived visual system. Never import a reusable mineral-rights voice pack or reuse another site's hero, FAQ, related rail, article ending, CTA, or decorative language.

## Voice lock

Write as a West Virginia mineral abstract desk. Use county deed books, severance clauses, heirship branches, parcel maps, paid decimals, curative files, Marcellus and Utica evidence, and a closing abstract. Never use first-person singular business narration, guaranteed value, instant-cash language, or a highest-offer claim.

## Visual lock

Preserve ICEYE's real Instrument Sans and Space Mono typography, black utility header, cinematic full-bleed carousel hero, wide image-card bands, expansive editorial spacing, black feature panels, crisp list modules, and dense dark footer. Slug pages use one wide hero image, a broad readable article, an Appalachian abstract-check FAQ, adjoining-record related links, and a closing-abstract CTA. Never insert a generic rounded card stack.

## Release blockers

- The street address may appear only inside a Google Maps embed query.
- No footer thumbnails, blank images, tiny images, floating media glitches, emoji, or Unicode-arrow decoration.
- Every slug has exactly one image: its hero image.
- No vertical one-character text, squeezed desktop columns, invisible copy, weak contrast, clipped sections, or overlapping header elements.
- Desktop header includes real routes, phone, and a clear contact CTA. Dropdowns work by hover and focus without a pointer gap; the mobile menu and every carousel control work.
- Contact forms contain exactly Name, Email, Phone, and Message.
- Every footer contains a Google Maps embed.
- The homepage hero contains an SEO-driven H1.
- Every page retains the ICEYE-derived fonts and theme.

Completion requires both machine gates, full desktop/mobile screenshot review, production deployment, and live alias verification.
